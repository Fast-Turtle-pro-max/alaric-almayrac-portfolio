# Portfolio – Alaric Almayrac

Site statique (HTML/CSS), sans dépendance.

## Mise en ligne avec GitHub Pages
1. Les images et CV sont déjà dans `assets/`.
2. `git init && git add . && git commit -m "Portfolio" && git branch -M main`
3. Crée un dépôt sur GitHub, puis `git remote add origin <url> && git push -u origin main`
4. Settings → Pages → Branch `main` / dossier `/ (root)`.
